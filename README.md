This repository containst the workflow action I use to convert docx files to PDFs. Download the .workflow directory and open directly to run. Inside, it runs the script contained in the .scpt file in this repo.

This works for me, but your mileage may vary. [Please let me know](mailto:broaders@mtholyoke.edu) if you run into issues — I'm happy to try to trouble shoot.

Since MacOS 26, the workflow asks for permission each time it is run. Please let me know if you find a way to permanently give permission.
